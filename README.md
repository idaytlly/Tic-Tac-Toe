# Tic-Tac-Toe ✖⭕✖
____________________________________________________________________________________________________
A Tic Tac Toe game where human player will compete against an AI opponent. The game is played on 3x3 grid and the objective is three of you marks in a row (horizontally, vertically or diagonally) before your opponent does!

## Features
- **Human vs Computer Mode**: Play against an AI opponent.
- **Intelligent AI**: The computer makes strategic moves to challenge the player.
- **Simple and intuitive interface.**
